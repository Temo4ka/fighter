# Словарь

Термины, которые встречаются во всех документах Fighter, по одной-две строки.
Остальные документы ссылаются сюда, а не объясняют термины заново.

Содержание: [1. Тело](#1-тело) · [2. Клипы и позы](#2-клипы-и-позы) · [3. Удары и бой](#3-удары-и-бой) ·

## 1. Тело

Как устроено тело бойца — [MECHANICS.md](MECHANICS.md), раздел 1.

| Термин | Что это |
|---|---|
| риг (`rig`) | описание тела: части, суставы с пределами и силой, параметры управления (`data/rigs/humanoid.json`) |
| часть тела | одна из 13: `Head`, `Torso`, `Pelvis`, `UpperArmL/R`, `ForearmL/R`, `ThighL/R`, `ShinL/R`, `FootL/R` |
| `…L` / `…R` | левые части — ближние к зрителю (боец смотрит вправо), правые — дальние |
| сустав (шарнир) | соединение части с родителем; угол в градусах, пределы — `limits` |
| кинематическая часть (posed) | таз и ноги: их ставит код по клипу, физика их не толкает |
| физическая часть | торс, голова, руки и оружие: тела Box2D, к позе их тянут моторы |
| контроллер таза | `PelvisController`: задаёт, где таз вдоль арены (ходьба, отбрасывание, выпад, стены, соперник) |
| мотор | скоростной мотор в суставе физической части: тянет угол к цели клипа |
| жёсткость | множитель силы и резкости моторов: атакующий клип её поднимает, попадание просаживает |
| удерживающий момент | момент мотора, которого хватает на позу при любой массе; не даёт тяжёлому бойцу «провисать» |
| перенос движения таза | физические части сразу получают изменение скорости таза, поэтому корпус едет с тазом |
| ragdoll | всё тело физическое, без управления: так боец падает в нокдауне |
| нокдаун | сильное попадание сбивает с ног; боец лежит и встаёт |
| нокаут | HP кончилось: боец лежит до конца боя |
| разворот | тело зеркалится относительно таза, чтобы смотреть на соперника |
| стоящая стопа (planted) | стопа на полу держит место, пока таз движется; нога сгибается (IK) |
| переступание (restep) | стопа, ушедшая от своей позы, переставляется поднятым шагом |

## 2. Клипы и позы

Как клипы играются — [MECHANICS.md](MECHANICS.md), разделы 2–3; поля файла — [DATA_FORMATS.md](DATA_FORMATS.md), «poses».

| Термин | Что это |
|---|---|
| клип | файл `data/poses/<имя>.json`: ключи, длительность; у ударов ещё активная фаза и ударные части |
| ключ | поза в момент `t`; между ключами углы меняются линейно |
| поза | углы суставов (и угол оружия `Weapon`) в один момент |
| призрак | целевая поза клипа без физики; в бою — категория `TargetPose`, в редакторе поз — слой правки |
| стойка | клип покоя: общая `stance` или стойка набора (`stance_sword` и др.); из неё идёт ходьба, к ней возвращается тело |
| цикл ходьбы | клип `walk` (в приседе — `crouch_walk`); ноги шагают за путём таза |
| слои позы | ноги и верх тела играют разные клипы |
| действие ногами | клип, у которого есть ключи ног (удар ногой, присед, низкий блок): он забирает ноги у ходьбы |
| шаг в действие | стопа, стоящая не там, где её ждёт действие ногами, шагает туда по дуге |
| поза покоя | где стоят ноги после остановки ходьбы, пока они не нужны действию |
| зеркальное действие | действие ногами с поменянными ролями ног — когда впереди правая нога |
| клип для другой руки | клип оружия, сыгранный с переставленными руками; на панели — суффикс ` (other hand)` |
| `active` | активная фаза удара `[от, до]`, с: только в ней контакт ударной части — попадание |
| `strikers` | ударные части клипа: попадание засчитывается только ими |
| `blendIn` / `blendOut` | за сколько секунд поза плавно переходит в клип и из него |
| `stiffness` (клипа) | жёсткость моторов, пока клип играет |
| `pelvisX` | дорожка сдвига таза ударом: выпад, перенос веса, отскок |
| `Weapon` (ключ позы) | угол оружия к предплечью — запястье |
| скорость воспроизведения (`rate`) | во сколько раз быстрее клип идёт в бою: DEX, скорость оружия, усталость |

## 3. Удары и бой

Как работают попадание и реакции — [MECHANICS.md](MECHANICS.md), раздел 4.

| Термин | Что это |
|---|---|
| удар (move) | `data/moves/<id>.json`: что делает удар (клип, урон, выносливость); кнопки и оружия он не знает |
| набор движений (moveset) | `data/movesets/<id>.json`: ввод → удар, блок, стойка; набор может наследовать другой |
| ввод | направление относительно соперника и кнопки: `Forward+Heavy`; кнопки — `Light`, `Heavy`, `Kick`, `Special` |
| окно одновременного нажатия | кнопки, нажатые в его пределах, считаются нажатыми вместе (`combo_window_sec`) |
| цепочка | удар, отменяющий восстановление предыдущего после попадания (`chain_to`) |
| попадание | контакт ударной части в активной фазе; у атаки оно одно |
| импульс попадания (`J`) | скорость сближения частей × их приведённая ударная масса, Н·с |
| ударная масса | масса звена, которым часть бьёт и принимает удар (стопа — всей ногой) |
| сила удара | импульс / масса жертвы × множитель места × (1 − броня), м/с; по ней — урон и ступень |
| ступень реакции | `None` < `Touch` < `Flinch` < `Stagger` < `Knockback` < `Knockdown` (касание, вздрагивание, пошатывание, отброс, нокдаун) |
| накопление (buildup) | удары подряд копятся и снижают пороги ступеней |
| стойкость (poise) | множитель порогов ступеней: CON, броня, щит в основной руке |
| отбрасывание (knockback) | скорость, которую попадание даёт тазу жертвы; затухает |
| просадка жёсткости | после попадания моторы слабее и постепенно восстанавливаются |
| блок, зона блока | блок держится кнопкой; зона (`High`, `Mid`, `Low`) выбирается направлением |
| выносливость, усталость | удары и блок тратят выносливость; на нуле боец устаёт и медленнее |
| прижат к стене | таз упёрся в стену за спиной: назад не шагнуть, отбрасывание гасит стена |
| «ничто не проходит сквозь соперника» | инвариант: части двух бойцов не входят друг в друга глубже допуска |
| расталкивание (spacing) | разведение тел: замедление сближения, плавный толчок, жёсткий толчок |
| остановка ноги | кинематическая нога, вошедшая в соперника, возвращается к касанию |
| заклинило (jammed) | удар ногой встретил соперника ещё в замахе: попадание, но не чистое |
| уступающая рука (yield) | рука, застрявшая в сопернике, мягчает и отходит к позе `yieldPose` |
| выталкивание (push-out) | попадание вплотную разводит тазы до `closeRange` |

## 4. Снаряжение и статы

Как статы становятся физикой — [MECHANICS.md](MECHANICS.md), раздел 7.

| Термин | Что это |
|---|---|
| STR, DEX, CON | сила, ловкость, телосложение; базовое тело — 10 |
| профиль (`PhysicalProfile`) | что статы и снаряжение дают телу: массы, моторы, скорости, HP, стойкость, выносливость |
| слот | место предмета: `Head`, `Body`, `Hands`, `Legs`, `Feet`, `MainHand`, `OffHand` |
| `MainHand` (основная, ведущая рука) | передняя рука; держит её предплечье `weapon.part` рига (`ForearmL`) |
| `OffHand` (другая рука) | задняя рука, `weapon.offPart` (`ForearmR`) |
| броня | доля поглощаемого урона части тела, 0…1 |
| оружие | отдельное тело на запястье держащего предплечья; дальность — `reach_m` |
| запястье | шарнир оружия у кулака; цель — ключ `Weapon` |
| двуручное оружие, хват | держит основная рука; кулак второй тянет к рукояти пружина хвата |
| щит | пластина на предплечье; в другой руке — средство блока, в основной — как оружие |

## 5. Инструменты

Как ими пользоваться — [TOOLS.md](TOOLS.md).

| Термин | Что это |
|---|---|
| debug-сборка | пресет `debug`: отладочный слой, панель, стенд, редактор поз |
| панель | текстовые строки состояния слева в debug-сборке (`P1 state`, `overlap`…) и журнал событий |
| категория отладки | группа отладочных примитивов (`Hurtbox`, `TargetPose`…), включается клавишей |
| стенд удара | `--stand`: один удар раз за разом перед манекеном, с замерами |
| манекен | второй боец на стенде, без ввода |
| досягаемость (reach) | как далеко вперёд от таза в начале удара уходит кончик ударной части в активной фазе |
| факт | тот же клип, сыгранный физикой стенда; слой редактора поз поверх призрака |
| `F5` | перечитать `data/` и начать бой заново |
| сеанс настройки | совместный с пользователем подбор чисел «на ощущение» |
| О.1…О.14 | номера решений по бою в [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) |
