# Fighter

Модуль боя для 2D-файтинга на C++23: два бойца из сочленённых тел на Box2D,
статы и снаряжение влияют на физику. Модуль войдёт в более крупный проект;
в этом репозитории — библиотека боя и песочница для её запуска.

> **Статус: фаза 1.5 (гибридное тело) завершена.** Таз и ноги бойца двигает код
> (контроллер и клипы), торс, голова и руки — физика на моторах. Бойцы стоят, ходят,
> бьют рукой и ногой; попадание раскачивает корпус и отбрасывает соперника тем меньше,
> чем он тяжелее, сильный удар сбивает с ног, и боец встаёт.
> Урона, блока, прыжка и раундов пока нет — это фаза 2. План — [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md),
> устройство кода — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), настройка бойца — [docs/TUNING.md](docs/TUNING.md), форматы данных — [docs/DATA_FORMATS.md](docs/DATA_FORMATS.md).

## Сборка

Нужны CMake ≥ 3.28, Ninja и компилятор с C++23. Библиотеки (SFML 3.1, Box2D 3.1,
nlohmann/json, Catch2) CMake скачает сам при первой конфигурации — ставить их не нужно.

**macOS** (Xcode или Command Line Tools):

```bash
brew install cmake ninja
```

**Windows**: Visual Studio 2022 с компонентом «Desktop development with C++».
Команды ниже выполняются в *Developer PowerShell for VS 2022* — там доступны MSVC,
CMake и Ninja.

### Две сборки

| Пресет | Для чего |
|---|---|
| `debug` | разработка: отладочный слой, ассерты, санитайзеры (ASan/UBSan на macOS) |
| `release` | как увидит игрок: оптимизация, отладочного кода в бинарнике нет |

```bash
cmake --preset debug
```

```bash
cmake --build --preset debug
```

```bash
ctest --preset debug
```

Запуск песочницы:

```bash
./build/debug/src/app/fighter_app
```

Для release замените `debug` на `release` во всех командах.

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| ходьба | `A` / `D` | `←` / `→` |
| вверх | `W` | `↑` |
| вниз (присед) | `S` | `↓` |
| джеб / сильный рукой | `F` / `G` | `K` / `L` |
| ногой в корпус / низкий ногой | `R` / `T` | `I` / `O` |
| блок | левый `Shift` | правый `Shift` |

Клавиши привязаны к физическому положению (scancode), поэтому работают в любой раскладке.
Зона блока выбирается направлением, пока зажат блок: вверх — голова, без направления или
вверх-вперёд — корпус, вниз — ноги («вперёд» — к сопернику).
Работают ходьба, джеб и удар ногой в корпус; сильный удар рукой, низкий удар ногой, присед
и блок пока ничего не делают — это фаза 2. `Esc` — выход.

## Debug-сборка

Вместо текстур рисуются хитбоксы, силы, скорости и другие отладочные данные,
слева — панель с состоянием.

| Клавиша | Действие |
|---|---|
| `F1` / `F2` / `F3` | только отладка / отладка поверх спрайтов / только спрайты |
| `F4` | показать или скрыть панель |
| `1`…`9`, `0`, `-` | включить или выключить категорию (список на панели) |
| `P` | пауза |
| `.` | один шаг симуляции (ставит на паузу) |
| `[` / `]` | замедлить / ускорить время (×0.1 … ×1) |
| `Backspace` | перезапустить бой |
| `F5` | перечитать `data/` (риги, позы, параметры боя, `visuals.json` и картинки) и перезапустить бой |
| `F6` | образцы всех отладочных категорий |
| `F7` | следующий стиль из `data/visuals.json` (сглаженный / пиксельный) |

Полезные аргументы командной строки:

```bash
./build/debug/src/app/fighter_app --screenshot shot.png --frames 120 --mode both
```

`--screenshot` сохраняет кадр и закрывает программу — удобно для баг-репортов.
`--mode debug|both|textures` — стартовый режим, `--showcase` — образцы категорий,
`--style smooth|pixel` — стиль из `data/visuals.json` вместо его `style`,
`--demo walk|fight|kick` — вместо клавиатуры сценарий (P1 ходит или подходит к P2 и бьёт),
`--log file.log` — дублировать лог в файл.

Параметры бойца (баланс, моторы, ходьба, удары) настраиваются в `data/` без перекомпиляции:
правите JSON, жмёте `F5`. Описание всех параметров — [docs/TUNING.md](docs/TUNING.md).

## Структура

```
src/
  core/     вектор, логгер, сигналы, цикл с фиксированным шагом, части тела
  debug/    отладочные примитивы и панель
  physics/  обёртка Box2D
  rig/      физическое тело бойца: части, шарниры, моторы, баланс
  anim/     позы и клипы
  stats/    статы, снаряжение, физический профиль
  combat/   публичный API боя: Battle, конфиги, результат, снимки для рендера
  render/   камера, отрисовка боя, отладочный слой
  app/      песочница: окно, ввод, цикл
tests/      тесты Catch2, по каталогу на модуль
tools/      утилиты разработчика: placeholder_gen рисует плейсхолдер-спрайты (docs/ART.md)
assets/     текстуры и шрифт (JetBrains Mono, лицензия OFL)
cmake/      настройки компиляции, зависимости, функция fighter_add_module
data/       риги, позы, параметры боя (JSON)
docs/       план, архитектура, настройка
```
