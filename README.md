# Fighter

Модуль боя для 2D-файтинга на C++23: два бойца из сочленённых физических тел
(active ragdoll на Box2D), статы и снаряжение влияют на физику. Модуль войдёт
в более крупный проект; в этом репозитории — библиотека боя и песочница для её запуска.

> **Статус: фаза 0 (фундамент) завершена.** Есть сборка, CI, игровой цикл,
> ввод для двух игроков, рендер и отладочный слой. Бойцы пока — кинематические
> прямоугольники: физика тела появится в фазе 1. План — [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md),
> устройство кода — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка

Нужны CMake ≥ 3.28, Ninja и компилятор с C++23. Библиотеки (SFML 3.1, Box2D 3.1,
nlohmann/json, Catch2) CMake скачает сам при первой конфигурации — ставить их не нужно.

**macOS** (Xcode или Command Line Tools):

```bash
brew install cmake ninja
```

**Windows**: Visual Studio 2022 с компонентом «Desktop development with C++».
Команды ниже выполняются в *Developer PowerShell for VS 2022* — там доступны MSVC,
CMake и Ninja.

### Две сборки

| Пресет | Для чего |
|---|---|
| `debug` | разработка: отладочный слой, ассерты, санитайзеры (ASan/UBSan на macOS) |
| `release` | как увидит игрок: оптимизация, отладочного кода в бинарнике нет |

```bash
cmake --preset debug
```

```bash
cmake --build --preset debug
```

```bash
ctest --preset debug
```

Запуск песочницы:

```bash
./build/debug/src/app/fighter_app
```

Для release замените `debug` на `release` во всех командах.

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| ходьба | `A` / `D` | `←` / `→` |
| прыжок | `W` | `↑` |
| присед | `S` | `↓` |
| рука / нога / блок | `F` / `G` / `H` | `K` / `L` / `;` |

Клавиши привязаны к физическому положению (scancode), поэтому работают в любой раскладке.
Удары и присед пока ничего не делают — это фаза 2. `Esc` — выход.

## Debug-сборка

Вместо текстур рисуются хитбоксы, силы, скорости и другие отладочные данные,
слева — панель с состоянием.

| Клавиша | Действие |
|---|---|
| `F1` / `F2` / `F3` | только отладка / отладка поверх текстур / только текстуры |
| `F4` | показать или скрыть панель |
| `1`…`9`, `0`, `-` | включить или выключить категорию (список на панели) |
| `P` | пауза |
| `.` | один шаг симуляции (ставит на паузу) |
| `[` / `]` | замедлить / ускорить время (×0.1 … ×1) |
| `R` | перезапустить бой |
| `F5` | перечитать конфиги (пока перезапускает бой) |
| `F6` | образцы всех отладочных категорий |

Полезные аргументы командной строки:

```bash
./build/debug/src/app/fighter_app --screenshot shot.png --frames 120 --mode both
```

`--screenshot` сохраняет кадр и закрывает программу — удобно для баг-репортов.
`--mode debug|both|textures` — стартовый режим, `--showcase` — образцы категорий,
`--log file.log` — дублировать лог в файл.

## Структура

```
src/
  core/     вектор, логгер, сигналы, цикл с фиксированным шагом, части тела
  debug/    отладочные примитивы и панель
  physics/  обёртка Box2D
  rig/      физическое тело бойца (фаза 1)
  anim/     позы и клипы (фаза 2)
  stats/    статы, снаряжение, физический профиль
  combat/   публичный API боя: Battle, конфиги, результат, снимки для рендера
  render/   камера, отрисовка боя, отладочный слой
  app/      песочница: окно, ввод, цикл
tests/      тесты Catch2, по каталогу на модуль
assets/     текстуры и шрифт (JetBrains Mono, лицензия OFL)
cmake/      настройки компиляции, зависимости, функция fighter_add_module
docs/       план и архитектура
```
