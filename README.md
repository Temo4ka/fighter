# Fighter

Модуль боя для 2D-файтинга на C++23: два бойца из сочленённых тел на Box2D, статы и снаряжение влияют на физику.
Модуль войдёт в более крупный проект; здесь — библиотека боя и песочница для её запуска.

Бойцы ходят, бьют руками, ногами и оружием, блокируют; попадания раскачивают корпус, отбрасывают, сбивают с ног;
бой идёт до нокаута или по таймеру. Что сделано и что дальше — [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md).

## Сборка

Нужны CMake ≥ 3.28, Ninja и компилятор с C++23; библиотеки CMake скачает сам при первой конфигурации.

- **macOS** (Xcode или Command Line Tools): `brew install cmake ninja`.
- **Windows**: Visual Studio 2022 с «Desktop development with C++»; команды — в *Developer PowerShell for VS 2022*.

| Пресет | Для чего |
|---|---|
| `debug` | разработка: отладочный слой, ассерты, санитайзеры (ASan/UBSan на macOS) |
| `release` | как увидит игрок: оптимизация, отладочного кода в бинарнике нет |

```bash
cmake --preset debug
cmake --build --preset debug
ctest --preset debug                # все тесты
ctest --preset debug-fast -j8       # без долгих сценарных (тег [slow], около 25 тестов по 10–60 с)
./build/debug/src/app/fighter_app   # песочница
```

Для release замените `debug` на `release`.

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| ходьба | `A` / `D` | `←` / `→` |
| вверх | `W` | `↑` |
| вниз (присед) | `S` | `↓` |
| лёгкий / сильный (`Light` / `Heavy`) | `F` / `G` | `K` / `L` |
| удар ногой / особый удар оружия (`Kick` / `Special`) | `R` / `T` | `I` / `O` |
| блок | левый `Shift` | правый `Shift` |

- Клавиши привязаны к физическому положению (scancode) и работают в любой раскладке. `Esc` в бою — пауза, в меню — назад.
- Какой удар делает кнопка, зависит от направления (относительно соперника) и набора движений оружия
  (`data/movesets/`). Без оружия `Light` — джеб, `Heavy` — сильный рукой, `Kick` — ногой в корпус; с мечом или молотом
  `Light` и `Heavy` — удары оружием. У `Special` без оружия удара нет.
- Зона блока выбирается направлением, пока зажат блок: вверх — голова, без направления или вверх-вперёд — корпус,
  вниз — ноги («вперёд» — к сопернику).

**Меню.** Fight → выбор бойцов (↑↓ выбрать, Enter подтвердить, ←→ сторона, Esc назад) → бой →
`Esc`: пауза (продолжить, заново, в меню) → итоги → меню. Клавиши debug-сборки — [docs/TOOLS.md](docs/TOOLS.md).

## Флаги командной строки

Без флагов боя песочница открывает главное меню; с любым из них сразу начинает бой.

| Флаг | Что делает |
|---|---|
| `--left <боец>`, `--right <боец>` | боец из `data/fighters/` для P1 / P2 (флаг боя) |
| `--demo walk\|fight\|kick` | сценарий вместо клавиатуры: P1 ходит или подходит к P2 и бьёт (флаг боя) |
| `--screenshot <файл.png>` | сохранить кадр и закрыть программу (флаг боя; с `--pose-editor` — кадр редактора) |
| `--frames <N>` | на каком кадре снимок, по умолчанию 60 (флаг боя) |
| `--mode debug\|both\|textures` | стартовый режим отладочного слоя, debug-сборка (флаг боя) |
| `--showcase` | образцы всех отладочных категорий, debug-сборка (флаг боя) |
| `--style <имя>` | стиль из `styles` в `data/visuals.json` (`smooth`, `pixel`) вместо его `style` (флаг боя) |
| `--stand <удар>` | стенд удара: боец раз за разом делает удар перед манекеном (флаг боя) |
| `--weapon <предмет>` | предмет из `data/items/` в основной руке — со `--stand` и `--pose-editor` |
| `--pose-editor [<клип>]` | редактор поз для `data/poses/<клип>.json`, только debug-сборка; без клипа — общая стойка |
| `--check-data` | проверить все файлы `data/` без окна; код выхода 0 — проблем нет |
| `--menu` | главное меню даже с флагами боя |
| `--keys <список>` | клавиши меню по одной за кадр, например `enter,down,esc` (скриншоты экранов) |
| `--round <сек>` | длительность раунда (быстро дойти до итогов) |
| `--log <файл>` | дублировать лог в файл |

Корень проекта (`assets/`, `data/`) — переменная окружения `FIGHTER_ROOT`, иначе каталог исходников на момент сборки.
Как пользоваться стендом, проверкой данных и редактором — [docs/TOOLS.md](docs/TOOLS.md).

## Структура

```
src/
  core/     вектор, логгер, сигналы, цикл с фиксированным шагом, части тела
  debug/    отладочные примитивы и панель
  physics/  обёртка Box2D
  rig/      тело бойца: части, шарниры, моторы, контакт двух бойцов
  anim/     позы, клипы, слои
  stats/    статы, снаряжение, физический профиль
  combat/   публичный API боя: Battle, конфиги, результат, снимки для рендера
  editor/   логика редактора поз
  render/   камера, отрисовка боя, отладочный слой
  ui/       меню и экраны
  app/      песочница: окно, ввод, цикл, окно редактора поз
tests/      тесты Catch2, по каталогу на модуль
tools/      утилиты разработчика: placeholder_gen рисует плейсхолдер-спрайты (docs/ART.md)
assets/     картинки и шрифт (JetBrains Mono, OFL); лицензии — assets/LICENSES.md
cmake/      настройки компиляции, зависимости, функция fighter_add_module
data/       риги, позы, удары, предметы, бойцы, параметры боя (JSON)
docs/       документация (таблица выше)
```
